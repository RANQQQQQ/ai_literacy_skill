# 校准曲线核验规则

仅在图表已被可靠识别为校准曲线时使用。

## 必查信息

1. 核对横纵坐标分别表示预测概率、观察概率还是其他量，并记录方向、范围和刻度。
2. 识别理想参考线及其图中依据，不因颜色或线型习惯直接猜测。
3. 建立每条模型曲线、颜色、线型、队列、结局和时间点的对应关系。
4. 判断展示的是表观结果、训练集、测试集、内部验证、外部验证还是无法确定。仅有 `testing` 标签不足以认定为独立外部验证。
5. 完整记录置信区间或误差带、分箱点、rug plot、直方图、预测概率分布和样本稀疏区域。
6. 检查是否提供样本量、重采样方法、校准截距、校准斜率、Brier分数、平均绝对误差或校准检验；没有显示时不得自行补充。

## 解释规则

- 校准曲线关注模型曲线与理想线的接近程度，不是越高越好或越低越好。
- 只有当横轴明确为预测概率、纵轴明确为观察/实际概率时：
  - 曲线在理想线上方通常表示观察风险高于预测风险，即模型低估风险；
  - 曲线在理想线下方通常表示观察风险低于预测风险，即模型高估风险。
- 坐标相反、定义不清或采用其他校准形式时，不得套用上述方向。
- 局部偏离只说明相应概率范围内的情况，不能自动扩展为整体校准结论。
- 置信带较宽、样本点稀少或底部概率分布很少的区域应降低判断强度。
- 视觉上接近理想线可以作描述性判断，但缺少不确定性信息时应谨慎比较模型优劣。
- 校准检验不显著不等于已经证明校准良好；应结合图形、截距、斜率、误差和样本量。
- 训练集或表观校准不能证明外部校准和泛化能力。
- 测试集校准图与训练集相似，不能单独证明无过拟合、稳定性或外部泛化。
- 校准表现不能单独证明临床应用价值或决策获益。

## 高风险措辞替换

- “曲线越高，校准越好” → 改为“通常越接近理想参考线，校准表现越好”。
- “曲线在参考线上方，因此模型高估风险” → 先核对坐标；在常见预测概率为横轴、观察概率为纵轴时，上方通常意味着低估风险。
- “P值不显著，证明校准良好” → 改为“该检验未显示明显失配，但不能单独证明校准良好”。
- “训练集和测试集曲线相近，说明模型稳定、没有过拟合” → 改为“图示校准形态相近；稳定性和过拟合不能仅凭该视觉比较确定”。
- “训练集校准良好，因此模型可以推广” → 改为“仍需确认验证设计；当前图不能支持推广结论”。

## 最终核验

- 是否完整记录坐标、范围、图例、参考线、模型曲线和附属概率分布？
- 是否先确认坐标定义，再判断高估或低估？
- 是否识别并实际使用理想参考线？
- 是否区分局部偏离和整体校准？
- 是否考虑置信带宽度和样本稀疏区域？
- 是否区分表观、训练、测试、内部验证和外部验证？
- 是否避免把不显著检验当成良好校准的证明？
- 是否避免从曲线相似推出稳定、无过拟合或泛化良好？
- 是否避免从校准表现直接推出临床价值？
