# ROC与校准曲线证据约束型自检

## 目标

基于用户实际提供的图像和上下文，给出可核验的科研图表解读。优先降低信息遗漏、数值误读、参考线误解、统计概念混淆、验证集混淆、过度推断和前后矛盾，而不是追求看似完整的结论。

本Skill目前只对ROC曲线和校准曲线提供专用规则。遇到其他图表时可以完成通用信息清点，但不得假称已完成该图表类型的专业核验。

## 证据边界

只使用用户提供的图像、图注、正文摘录、数据或说明。明确区分信息来源：

- **A：直接事实**——图中或用户提供的材料明确显示；
- **B：合理解释**——由图形关系和适用的统计规则支持；
- **C：无法确定**——需要图注、正文、原始数据、分析代码或额外检验。

不要把B写成A，也不要把C补成确定事实。图中没有显示某项信息时，只能说“当前材料未提供”，不能推断研究本身没有报告。

## 执行流程

### 1. 判定范围并选择规则

先判断每个子图属于ROC曲线、校准曲线、其他图表或无法确定。

- 发现ROC曲线时，读取并应用 [references/roc.md](references/roc.md)。
- 发现校准曲线时，读取并应用 [references/calibration.md](references/calibration.md)。
- 一张图同时包含两类曲线时，分别应用两个模块。
- 无法可靠判断类型时，不套用专用规则，说明需要什么信息才能确认。

不要仅凭论文主题或图形外观确定类型；应结合坐标轴、图例、标注和参考线。

### 2. 完整性清点

在解释之前，清点：

- 子图总数、标签和类型；
- 图像是否裁剪、遮挡、重叠或分辨率不足；
- 横纵坐标名称、方向、范围和刻度；
- 图例、颜色、线型及其对应对象；
- 模型、分组、队列、结局和时间点；
- 训练集、内部验证集、外部验证集或无法判断；
- 样本量、评价指标、置信区间、参考线和图内注释。

每项标记为“已明确提供”“当前材料未提供”或“存在但无法可靠辨认”。不得把未提供的信息计作已识别事实。

### 3. 原样转录关键数值

先转录，后解释。对每个关键数值记录：

- 原样数值；
- 所属子图；
- 对应模型、颜色、数据集、结局或时间点；
- 图中位置或可见依据；
- 读取置信度：高、中、低。

分辨率不足时使用“约为”“可能为”或“无法精确辨认”。不得把估读值伪装成精确值。置信区间必须与点估计和模型正确配对。

### 4. 解释图形语义

只在坐标、图例、参考线和数据集性质得到确认后解释曲线。应用对应专用规则，区分：

- 图形或数值上的描述性差异；
- 有统计检验支持的差异；
- 仅凭当前材料不能判断的差异。

比较多个模型时，不因任务要求而强行排序。曲线接近、交叉、置信区间不清或缺少统计检验时，应降低判断强度。

### 5. 建立“判断—证据”对应关系

每项主要判断必须标记A/B/C，并指出具体图像依据。若一项结论找不到可定位证据，则删除、降级或移入“无法确定”。

### 6. 执行结论权限检查

在形成总结前，逐项排除：

- 将AUC写成准确率；
- 将数值更高写成统计学显著更优；
- 将校准检验不显著写成已经证明校准良好；
- 将训练集结果写成泛化能力；
- 将内部验证写成外部有效性；
- 将区分能力或校准表现直接写成临床应用价值；
- 将相关关系写成因果关系；
- 推测未提供的样本量、研究设计、统计方法或验证方式。

证据不足时输出受限定的描述性结论。必要时明确写：“当前材料只能支持描述性陈述，不能单独形成完整的研究结论。”

### 7. 独立复核并修正

完成初稿后，以核验者视角重新检查：

1. 是否遗漏子图或图内明确提供的信息；
2. 模型、颜色、线型、数值、队列和时间点是否一一对应；
3. 训练集、内部验证集和外部验证集是否混淆；
4. 参考线是否已识别且实际用于解释；
5. 统计术语是否使用正确；
6. 是否存在前后矛盾；
7. 是否出现当前材料没有的信息；
8. 是否把低置信度估读写成精确事实；
9. 最终结论是否超过证据边界。

发现问题时先修改最终回答，再报告简洁的自检结果。不要展示冗长的内部推理过程。

## 输出格式

### 1. 图像与信息完整性

说明子图数量、图像质量，以及关键材料属于已提供、未提供还是无法辨认。

### 2. 逐子图信息表

| 子图 | 图表类型 | 坐标与参考线 | 模型/队列对应 | 可见关键数值 | 读取置信度 |
|---|---|---|---|---|---|

### 3. 主要判断与证据

| 判断 | 等级A/B/C | 图像或材料依据 | 解释边界 |
|---|---|---|---|

### 4. 核心信息与受限定结论

先概括当前材料支持的核心信息，再给出一句受证据约束的描述性结论。证据不足时不得强行形成学术结论。

### 5. 无法确定与引用前待核对事项

列出需要回到图注、正文、原始数据或代码核对的内容。

### 6. 自检记录

| 自检项目 | 结果 | 修正或限制 |
|---|---|---|

| 数值与对象对应 | 通过/未通过/无法判断 | |
| 参考线解释 | 通过/未通过/不适用 | |
| 数据集性质 | 通过/未通过/无法判断 | |
| 统计概念 | 通过/未通过 | |
| 结论边界 | 通过/未通过 | |

## 可靠性原则

- 本Skill降低误读风险，不保证答案必然正确。
- 自检不是独立事实验证；关键结论仍应回到论文、数据或代码核对。
- 用户提供图注、正文或原始结果时，应使用它们交叉核验，但需注明信息来源。
- 对自己生成的图，优先建议用生成图表的原始统计输出核对精确数值。
- 不把未经测试的其他图表类型描述为本Skill已经验证的能力。
